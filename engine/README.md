# GANGSTER: NEW YORK — Java / LibGDX OpenGL ES prototype

This is the 3D Android engine track, separate from the earlier 2D app at repository root. It uses Java 17, LibGDX 1.13.1 and requests OpenGL ES 3.0 on Android.

## Current prototype
- Landscape Android app and third-person follow camera.
- Touch joystick, swipe-to-look and contextual enter/exit vehicle control.
- Original low-poly OBJ/MTL assets generated by `tools/generate_models.py`: Carl, sedan, trees, streetlight, low/mid/tower buildings and warehouse.
- Procedural Manhattan-inspired starter district with avenues, sidewalks, buildings, park props and static pedestrian placeholders.
- Basic vehicle steering, acceleration, reverse and first objective/reward trigger.

This is an early prototype, not the complete seven-region game. Moving traffic, pedestrian AI, police, animation, interiors, map streaming and the other six regions remain future work.

## Build
Run the asset generator first, then build with JDK 17 and Android SDK 35:
```bash
python3 engine/tools/generate_models.py
cd engine
gradle :android:assembleDebug
```
APK: `engine/android/build/outputs/apk/debug/android-debug.apk`.

GitHub Actions runs the generator and builds a debug APK on pushes under `engine/` or by manual workflow dispatch.

## Models
OBJ + MTL meshes are original procedural low-poly models, not ripped from another game. They can be imported and edited in Blender. Optional GLB interchange copies are exported if Python package `trimesh` is installed.
